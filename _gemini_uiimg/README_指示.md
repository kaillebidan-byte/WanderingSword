# 焼き込みUI画像 日本語化 — Gemini委託キット

生成 2026-06-25。戦闘上部バー等の「画像に焼き込まれた文字」を日本語化するための素材＋指示。

## これは何か
ゲームのUI操作ヒントは **画像（テクスチャ）に文字が焼き込まれて**いて、テキスト翻訳(locres)では直せない。
言語別画像（英語/繁体字）が同梱されており、本MOD(簡体字運用)はベース画像を読むため中文表示になる。
→ **日本語画像を作ってベースに上書きすれば日本語化できる**（機構は実機実証済み）。

漢字単語ボタン（手動/自動 等）は**繁体字画像の流用で対応済み**（無編集）。
ここで委託するのは、**英語/中文と字形が違うフレーズ系**＝Geminiで画像内テキストを日本語に置換してほしいもの。

## 素材は2種類（必ず両方をGeminiに渡す）
- **`src/`** … 英語版。**意味を読むため**の参照（Select Grid 等）。
- **`src_簡体字/`** … 簡体字版（同名）。**レイアウトの参照**。日本語も漢字なので、**文字の位置・大きさ・改行は簡体字版に合わせる**のが正解。
  - 英語は語長が違って枠からはみ出る（例 Information）ため位置参考にならない。**簡体字版を見れば「どこにどう漢字を置くか」が一目で分かる**。
- 編集対象（土台）は**英語版PNG**でも簡体字版PNGでもよいが、**仕上がりの文字配置は簡体字版に倣う**こと。

## Geminiへの基本指示（各画像 共通プロンプト）
> この画像はゲームUIの操作ガイドです。**画像内の英語テキストだけを日本語に置き換えて**ください。
> 厳守事項:
> - **ボタンのアイコン（◯で囲まれた A/B/X/Y/LB/RB/LS/RS、十字キー等）は一切変更しない**。位置も維持。
> - **フォントの太さ・白色・縁取り・サイズ感を元画像に合わせる**。
> - **背景は透過(アルファ)のまま**。塗りつぶさない。
> - **出力は元画像と完全に同じピクセル寸法**（例 1920×50）。リサイズ・トリミング禁止。
> - 余計な要素を足さない。レイアウト(各ラベルの横位置)は元のまま。
> - **文字の位置・大きさ・改行は、同名の簡体字版画像(`src_簡体字/`)に合わせる**（日本語も漢字なので簡体字の配置が最適な手本。英語版は語長が違うので位置の参考にしない）。
> 置換する語の対応は下表のとおり。

## 返却方法
- Geminiが出した日本語版PNGを **`返却/` フォルダに、元と同じファイル名**で保存（例 `Gamepad_A5.png`）。
- 寸法は元と同一必須（`_manifest.json` に各寸法あり）。透過PNG(RGBA)。
- そろったら「再インポートして」と指示 → こちらで `import_ja_png.py` でuexpへ注入・pak・deploy。

## 注意
- 文字数が増えると枠から溢れる恐れ。長い語は短縮可（例 戦闘速度→倍速、カメラ調整→視点等）。実機で確認しながら調整。
- 寸法が1pxでも違うと再インポートで弾く（安全装置）。Geminiが寸法を変えがちなので、返却後に必要なら当方で同寸リサイズして注入する。
