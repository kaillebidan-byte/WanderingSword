# Wandering Sword 翻訳Vault

このフォルダは **Obsidian の Vault(=メモの金庫)** だよ。
中身はぜんぶ普通のテキスト(`.md`)。Obsidianで開くと、リンクや検索が効く「翻訳の辞書＋設定資料」になる。

## フォルダの意味

- `00_ルール/` … 翻訳の土台。**口調・一人称ルール**と**基本翻訳ルール**。ここが監査の憲法。
- `10_人物/` … キャラ名の訳語・設定・喋り方。
- `20_地名・門派/` … 地名や組織名(武林盟など)の訳語統一。
- `30_用語・武術/` … 技名・アイテム・世界観用語。
- `_テンプレート/` … 新しいノートを作るときの雛形。コピーして使う。

## 使い方の核(これだけ覚えればいい)

1. 新しい固有名詞が出たら、`_テンプレート/` の雛形をコピーして該当フォルダに置く。
2. ノートの先頭にある `---` で囲まれた部分(フロントマター)に、tagsや訳語を書く。
3. 訳がまだ揺れてるものだけ `status: 仮訳` を付ける。確定は無印でいい。

## 次の一歩

Obsidian を入れて、このフォルダ(`Wandering Sword翻訳`)を「Vaultとして開く」だけ。
