# 引き継ぎ: `## 機械置換` 表の種付け(Opus直轄・別セッション向け)

作成 2026-06-16 / 種別: ペルソナ整備(コスト削減基盤)。**このファイルで完結**。全体像は [CLAUDE.md](CLAUDE.md)、手順正本は [RUNBOOK_翻訳自動実行.md](_tools/RUNBOOK_翻訳自動実行.md)。

## これは何/なぜOpusか
フェーズ2校正は手動Sonnet運用で、コスト削減の主軸は **`mechanical_pass.py` による機械置換の先行適用**。
そのためには各キャラのペルソナ `10_人物/<キャラ>.md` に **`## 機械置換` 節**(曖昧さゼロの1:1 JA→JA置換)が要る。
**この表を書くのは「安全な置換かregister依存か」の判断＝Opus直轄**(Sonnetは走らせるだけ)。
未完了の確定キャラ(2026-06-16時点で残173・先頭から全て確定)に、処理順で逐次種付けする。

## スコープと進め方
- `python _tools/seed_queue.py` で**現在地以降の未完了キャラ**を status・節有無つきで一覧(`✓`=節あり)。
- **一気に全部やらない**。Sonnetの処理位置の**少し先(目安10体)を種付け**し、消化されたらまた先を種付け。
- 対象は `status: 確定` のみ。`仮訳/未確定`(関門で停止)・`保留`(宇文逸)は**種付けしない**。
- 既に `## 機械置換` 節があるキャラ(司馬鈴=完了済の参考例)は飛ばす。

## 1キャラの種付け手順
1. **MTの実態を見る**(WS_CHARで化け回避): `set WS_CHAR=<キャラ>` →
   `python _tools/pending_char.py --audit "<キャラ>"`(出力は `$WS_TMP/char_audit.json`)で**現訳ja(=生MT。未校正)**を一覧。
   併せて `python _tools/persona_derive.py "<キャラ>"`(原文の自称・二人称統計)で zh の呼称を把握。
2. **ペルソナを読む**: `10_人物/<キャラ>.md` の `一人称`/`二人称・呼称`/`校正変換規則`/`原文の自称・呼称`、
   および [00_ルール/関係性・呼称マップ.md](00_ルール/関係性・呼称マップ.md)(宇文逸・他キャラへの呼び方の正本)。
3. **安全な1:1だけ**を `旧 => 新` で列挙(下記カテゴリ参照)。MTの**予測される表記ゆれ**を網羅(哥哥→兄さん/兄様/お兄さん 等、変種は有限)。
4. ペルソナの `## 完成例` の**直前**に `## 機械置換` 節を挿入(司馬鈴のブロックがテンプレ。先頭に「register依存は入れない」注記を付ける)。
5. **検証**: `python _tools/mechanical_pass.py --dry`(WS_CHAR設定済)。現訳(生MT)に対し**ヒット行数**が出る=Sonnet実行時に自動処理される量。
   `[警告]` が出たら危険エントリ(代名詞/コピュラ)が混入 → 表から外す。**適用(--dry無し)はしない**——適用はSonnetが校正時に行う。

## 入れてよい/だめ
**入れる(安全な1:1・曖昧さゼロ)**:
- **半端漢字の自称**: 名で自称するキャラの `名児→名`(例 鈴児→鈴)。原文 `XX儿` をMTが「XX児」と直訳した残り。
- **固定呼称**: 宇文逸へ/年長へ/弟妹への確定呼称。MT変種を全部 → 確定形(例 宇文兄さん/兄様/お兄さん → 宇文お兄ちゃん)。
- **○○姐姐/哥哥 の格**: `○○お姉さん→○○姉さん` 等、そのキャラの確定形へ(呼称マップ準拠)。
- **師匠↔師父** などキャラ確定の表記統一。
- **生の中国語残り**: MTが訳し損ねた語(例 阁下/姑娘 が生で残る等)で**訳が一意**なもの。

**入れない(register依存=LLM判断。mechanical_passのガードも自動拒否する)**:
- 一人称代名詞そのもの(`私/我/俺`…)。場面で訳し分けるべき=判断。
- コピュラ・終助詞(`です/ます/だわ/のよ/かしら`…)。文単位の作り直しが要る。
- 笑い声の選択(`嘿嘿/嘻嘻`→ どれにするか)。キャラと場面の判断。
- 1文字キー(衝突しやすい)。

## 環境(Windows)
- `set WS_CHAR=<キャラ>`(PSは `$env:WS_CHAR="<キャラ>"`)/ `$env:PYTHONIOENCODING="utf-8"` / `$env:WS_TMP="$proj\_ws_tmp"`。
- **CJKを含むPython/JSONは `python -`/heredoc/パイプ厳禁**。必ず .py / .md ファイルに書いて実行(Writeツールは正しいUTF-8)。
- 節の挿入はEditツールで `## 完成例` をアンカーに。`mechanical_pass.py` の内蔵ガードが危険置換を弾くので事故は文を壊さない。

## 完了の目安
全確定キャラに節が付き、`seed_queue.py` の「種付けが必要」が0になれば基盤完成。以後はSonnetが mechanical_pass→残り校正で自走できる。
