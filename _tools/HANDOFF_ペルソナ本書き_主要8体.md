## このタスク
強化ペルソナ「本書き」の続き。**監査で新たに確定した主要8体をフル本書きする**。
8体は全員、行数≥400の主要キャラなのにトリアージ個別判定表から漏れ、旧ペルソナのまま（自称が「私」に潰され、声の核なし、一部 status:仮訳）。前セッションで原文監査を済ませ、**全員が多面（モード切替）確定**。下の監査結果を起点に声の核を起こす。

## 運用ルール（厳守・既出だが重要）
- ファイル書込は**bash heredoc**。Write/Editはマウント同期ラグでbash側に反映されない。書込後 `grep -c 声の核` `grep -c 校正変換規則`、および文字化け(U+FFFD)が0であることを確認で必ず検証。
- 入力JSON等もbash heredoc。/tmpは使わず作業フォルダ内（WS_TMP）。
- gitはWindowsネイティブ実行（sandboxからは不可）。
- 出力は簡潔・chain-of-thought非開示・1回で完了報告。
- **deploy（deploy_to_game.py）と校正本体（apply_char.py）はしない。ペルソナMD編集のみ。**
- 校正スケジュール `wandering-sword-proofread-daily`（6時/18時稼働）は触らない。

## 本書きの標準フォーマット（必須セクション）
1. front matter: `status: 確定` / `更新日: 2026-06-14`
2. `## 声の核（モード切替が本体）`＝二段以上のモードと**切替条件**。語尾でなく条件を固定。一人称（相手・場面別）・二人称もここに。
3. `## 発話優先順位` / `## 感情表出` / `## 言わないこと（思考禁止）` / `## 校正変換規則`
4. `## 完成例（原文起こし・MT非引用／声の校正用）`＝**MT引用禁止。原文zhから起こす**。モード別に数本。
- 見本: `10_人物/絶無心.md`（皮肉⇄敬意）、`10_人物/殷無矜.md`（威厳⇄叱責）、`10_人物/玄離.md`（慇懃表⇄腹黒裏）。

## 手順（1体ずつ）
1. `python3 _tools/persona_derive.py "<名>" 14` で原文の自称・二人称マーカー＋代表セリフ（原文zh）取得。素材は必ず原文。MT訳・旧代表セリフから声を起こさない。
2. 必要なら `00_ルール/関係性・呼称マップ.md` で宇文逸への呼称等を裏取り（≥100行キャラのみ収録）。
3. 下の監査結果のモード核を起点に、原文で裏取りしつつ声の核を書く。
4. bash heredocでMDをフル上書き（旧ヘッダごと差し替え）。**現行ペルソナの核自称が「私」等に潰れているので必ず正す**。
5. grep で検証（声の核1・各ブロック有・文字化けU+FFFD=0）。
6. 3〜4体で区切り完了報告。
