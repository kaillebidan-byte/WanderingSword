# 手順書 — 手動校正サーバ（セッション非依存で自分で動かす）

> Claude のセッションやレートリミットに**一切依存しない**運用手順。
> すべて**自分のPowerShellウィンドウ**で実行する。Claudeが落ちてもサーバは動き続ける。
> 対象: [proofread_server.py](proofread_server.py) / [apply_manual.py](apply_manual.py)。仕様は [SPEC_手動校正Web.md](SPEC_手動校正Web.md)。

---

## 1. 起動（いちばん簡単・推奨）

エクスプローラで `_tools\手動校正\proofread_start.ps1` を**右クリック →「PowerShell で実行」**。
- 約6秒後にブラウザが自動で開く（http://127.0.0.1:8765）。開かなければ手動でこのURLを開く。
- このウィンドウは**開いたまま**にする（閉じる＝サーバ停止）。

> 右クリックメニューに出ない／実行がブロックされる場合は、PowerShellを開いて次を貼り付け:
> ```powershell
> powershell -ExecutionPolicy Bypass -File "C:\Users\kaill\Claude\Projects\Wandering Sword翻訳\_tools\手動校正\proofread_start.ps1"
> ```

## 2. 起動（手動でコマンドを打つ場合）

PowerShell を開いて、次の3行を貼り付け:
```powershell
cd "C:\Users\kaill\Claude\Projects\Wandering Sword翻訳"
$env:PYTHONIOENCODING = "utf-8"
python _tools\手動校正\proofread_server.py
```
表示が `→ http://127.0.0.1:8765` になったらブラウザでそのURLを開く。

## 3. 停止

- サーバを動かしているウィンドウで **Ctrl + C**。
- ウィンドウを見失った時は、別のPowerShellで:
  ```powershell
  Get-NetTCPConnection -LocalPort 8765 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
  ```

## 4. 修正の検証（T1・ゲーム非破壊）★まず必ずこれ

校正で何件か直したあと、**別のPowerShellウィンドウ**で:
```powershell
cd "C:\Users\kaill\Claude\Projects\Wandering Sword翻訳"
$env:PYTHONIOENCODING = "utf-8"
python _tools\手動校正\apply_manual.py --verify
```
`✅ 検証OK（ゲーム非破壊）` が出れば、編集がlocresに正しく載り、タグ・接頭辞・非編集行が壊れていない。
（`manual_edits.json` が空なら「編集なし」と出る。サーバは止めなくてよい。）

## 5. ゲームへ反映（デプロイ）★1発。ゲームを閉じてから

**検証 → locres適用＋再パック → Paksへコピー を1コマンドで実行。**

エクスプローラで `_tools\手動校正\proofread_deploy.ps1` を右クリック →「PowerShell で実行」。
- 中で `python _tools\手動校正\apply_manual.py --deploy` が走り、①検証②適用+再パック③ゲームへコピーを順に実施。
- `✅ デプロイ完了` が出たらゲームを起動して確認。
- 検証でNGが出たら**デプロイは中止**（ゲームは無変更）。表示された行を直してから再実行。
- `Access denied` なら PowerShell を**管理者として実行**。ゲームが起動中だと「閉じて再実行」と出る。

手で打つ場合:
```powershell
cd "C:\Users\kaill\Claude\Projects\Wandering Sword翻訳"
$env:PYTHONIOENCODING = "utf-8"
python _tools\手動校正\apply_manual.py --deploy
```

> 検証だけしたい（配置しない）時は `--verify`、適用+再パックだけは引数なし、再パック無しは `--no-pack`。
> 反映後にサーバ画面の現訳も最新にしたい時は、サーバを再起動（手順1か2）。
> ※pakが200MB超なのは正常（翻訳済みの画像・マップ・UIアセットを含むため。テキストのみの初期版は約9MB）。

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| ブラウザが「接続できない」 | サーバのウィンドウが開いているか確認。なければ手順1で起動 |
| 起動時 `Address already in use` / ポート使用中 | 手順3の停止コマンドでPID解放 → 再起動 |
| 文字化け・`cp932`エラー | `$env:PYTHONIOENCODING = "utf-8"` を打ってから python を実行（手順2の2行目） |
| python が残ったままか確認 | `Get-Process python -ErrorAction SilentlyContinue` |
| python を全部止める（最終手段） | `Get-Process python | Stop-Process -Force` ※他のpython作業も巻き込むので注意 |

## 7. 仕組み（安全面）

- 編集は `_phase4_proofread\manual_edits.json`（オーバーレイ）にだけ書かれる。**locresは手順5を実行するまで触らない**。
- 保存時に `$@$`接頭辞・色タグ・`#nl`/`\r\n`/`{0}` の破壊を弾く（壊れた修正は保存できない）。
- 失敗しても `_backup\aaWanderingSword_JP_P.original.pak` から復元可能。
- T1検証(`--verify`)は locres のコピー上で行うので `_work` もゲームも壊さない。
