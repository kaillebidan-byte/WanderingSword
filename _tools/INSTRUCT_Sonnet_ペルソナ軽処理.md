# 指示書：ペルソナMD「軽処理」強化（Sonnetワーカー用）

(bashでは /sessions/<id>/mnt/Wandering Sword翻訳)

## 役割
確定済みペルソナMD（10_人物/<キャラ>.md）の「軽処理」分類キャラに、4ブロックを追加して声を立てる。
**モード切替の本書きはしない**（それはメイン=Opus直轄）。単一モードのキャラだけを型に沿って強化する。

## 対象の選び方
- 索引: `_phase4_proofread/_persona_triage.md` の【軽処理＝単一モード】に挙がったキャラのみ。
- **除外**: 同ファイルの【真の切替＝本書き要 27件】には絶対に手を入れない。
- **重複回避**: 各MDの `更新日:` が `2026-06-14` のものは処理済み。`2026-06-13` 以前のものだけ処理する。
- 1チャンク10〜15キャラ程度で区切り、各キャンクごとに完了報告。

## 手順（1キャラずつ）
1. `10_人物/<キャラ>.md` を読む（既存の一人称・二人称・口調・性格・語尾・原文根拠は**活かす**）。
2. 原文サンプルを取る: `python3 _tools/persona_derive.py "<キャラ名>" 12`
   （※素材は必ず原文zh。MT訳・代表セリフ例から声を起こさない）。
3. 「## 代表セリフ例」セクション以降（⚠️校正前MT・文字化け含む）を**丸ごと削除**し、
   下記4ブロック＋完成例に差し替える。冒頭の既存記述（一人称/二人称/口調等）は残す。
4. `更新日:` を `2026-06-14` に。`status: 確定` は維持。

## 追加する4ブロック＋完成例（雛形）
- `## 発話優先順位（どう考えて喋るか）` … 何を優先して発言するか4項目
- `## 感情表出` … 喜/怒/哀/含み等を「直接言わず、どう出すか」
- `## 言わないこと（思考禁止）` … 自己憐憫しない/感情を名前で説明しない 等＋キャラ固有の禁止
- `## 校正変換規則` … 一人称の当て方/MT臭の戻し方/固有の禁止語（時代錯誤語など）
- `## 完成例（原文起こし・MT非引用／声の校正用）` … 原文から起こした到達目標3〜5本（MT引用禁止）

**完成見本**: `10_人物/肖寒光.md`（軽処理の標準形）を必ず参照してから書く。

## 制約（厳守）
- 書き込みは **bash heredoc** で行う（ファイル編集ツールはマウント同期ラグで反映されない）。
  1回のheredocは長すぎないように（途中で切れたら追記で補う）。書込後 `grep -c '�'` で文字化け0を確認。
- **ゲームへのdeploy（deploy_to_game.py）はしない。校正本体（apply_char.py）もしない。** ペルソナMDの編集のみ。
- モード切替の兆候（相手で一人称/敬語が二段に変わる、謙譲語と罵り/俗称が同居）を見つけたら、
  そのキャラは**触らず**、報告の「エスカレーション候補」に名前を挙げる（メインが本書きする）。

## 完了報告（必須・簡潔に）
- 処理したキャラ名一覧（件数）
- 各ファイルの文字化けチェック結果（全て0か）
- エスカレーション候補（モード切替を疑ったキャラ）
- 次チャンクの開始位置
