# 語調技法カタログ（Legend of Mortal 訳 参考）

別ゲームの高品質JP訳から、**個性の出し方=役割語の運用**を技法として抽出した参考資料。

LoMキャラの模倣ではなく、ペルソナ設計・整合性チェック時の「この性格にはこの型」の即引き用。

各例は `中国語原文 → 日本語訳` の対。原文がどう個性づけされたかを見る。

## 一人称の使い分け


### 一人称「俺」

- 我错了！我错了还不行吗？  →  **俺が悪かった！ 悪かったってば！**
- 所以我乃局外之人，不按你规矩走，最是难防难闪。你可得小心了。  →  **だから俺は局外の人間だ、お前のルールには従わない、最も防ぎ難く避け難いぞ。気をつけるんだな。**
- 我师父，就是夏侯兰啊。  →  **俺の師匠は、夏侯蘭ですよ。**
- 首先我们就不会聘用魔教中人，见到就立即杀了。  →  **そもそも俺たちなら魔教の人間なんて雇わねえ、見つけ次第殺してるさ。**
- 我？我这样的无名小卒，几时劳她费心了。  →  **俺？ 俺のような名もなき下っ端に、いつからそんな気遣いを？**

### 一人称「私」

- 我、我不大爱吃这个～来点甜的如何？  →  **わ、私それあんまり好きじゃないの～甘いものにしてくれない？**
- 你们便是二人合力与我相斗，我又何惧之有！递招过来便是。  →  **君たち二人が力を合わせて私と戦おうとも、何を恐れることがあろう！かかって来い。**
- 小僧若胜了你，你可得听我一句劝。  →  **拙僧が勝ったら、私の説教を聞いていただきますよ。**
- 且慢，我去吧。  →  **待て、私が行こう。**
- 他们不是我。唐某不曾向你保证过任何事情。  →  **彼らは私ではない。唐某は貴様に何も保証したことはない。**

### 一人称「僕」

- 赎回外堡好啊，不然我都没位子睡。  →  **外堡の買い戻し、賛成っす。じゃないと僕の寝る場所がない。**
- 我哪知道你？  →  **僕が君のことなんて知るわけないだろう？**
- 不知你改日得闲，是不是能够指点我一两手呀？  →  **もし後日お暇があれば、僕にも少し手ほどきをしていただけませんか？**
- 我当然是在戈壁沙漠就抓一把沙子寄给你了。  →  **僕はもちろん砂漠で砂を一掴み送るっすよ。**
- 好，那你可要保护好我喔。  →  **よし、なら僕のことをしっかり守るのだぞ。**

### 一人称「あたし」

- 我怎么知道呢？  →  **あたしが知るわけないだろ？**
- 是吗……他也对我说了类似的话。  →  **そうか……あいつ、あたしにも似たようなことを言ってたな。**
- 你可别太得意哦，下回再切磋，就是我向你讨教了。  →  **調子に乗るんじゃないよ。次に手合わせする時は、あたしが教えを請う番だからね。**
- 你别取笑别人的不幸，我──  →  **人の不幸を笑わないでよ、あたしは──**
- 来日江湖再逢，你我姊弟，后会有期。  →  **いつの日か江湖で再会しよう。あたしたち姉弟、また会う日まで。**

### 一人称「わし」

- 这么玄吗？你说吧，反正老朽再钓也没多少时日了。  →  **そんなに玄妙なのか？言ってみよ、どうせわしが釣りをできる日も残り少ないのじゃ。**
- 你上楼去爹卧房，将架上木匣子拿来。  →  **二階のわしの寝室へ行き、棚の上にある木の箱を持ってきてくれ。**
- 是老夫杞人忧天了，你和瑞笙小友还差得远去了。  →  **わしの杞憂であったか、瑞笙の若造には遠く及ばんな。**
- ……老朽想不通。  →  **……わしにはわからん。**
- 何止，碰着我们，说话都客气了几分。想是卧云岗那一役，让他们不敢再小觑唐门了。  →  **それどころか、出くわしても口調が丁寧だったぞ。臥雲崗の一戦で、唐門を侮れなくなったんだろう。**

### 一人称「拙者」

- ……向某纵能胜你，也在百招以后。这场胜负暂且按下。  →  **……拙者が勝てるとしても、それは百手先のことになろう。この勝負、ひとまず預けておく。**
- 在下唐门赵活。  →  **拙者は唐門の趙活。**
- 我也上堡楼看看情况。  →  **拙者も櫓に登って状況を見てこよう。**
- 在下山野粗人，说话不得体，也是有的。  →  **拙者は山育ちの粗忽者ゆえ、言葉が過ぎることもありましょう。**
- 可是向某说的不对？  →  **拙者の勘違いか？**

### 一人称「妾」

- 妾身魏菊，恭迎掌派人。  →  **妾身、魏菊。掌派人をお出迎えいたします。**
- 你既不肯称他为兄长，赵兄亦有了心仪之人，那你只好当他的妾，服侍他了。  →  **彼を兄と呼ばぬなら、趙さんには意中の人がいる。ならば君は彼の妾となり、仕えるしかあるまい。**
- 这些我都没意见，有一日他看上了一位貌美的小姑娘，想纳为妾室。  →  **それだけならまだしも、ある日、美しい娘さんを見初めましてね。妾にしたいと言い出したんです。**
- 我就是你爹的妹妹的丈夫的第三个兄长的小妾的姑姑。  →  **わっちはそなたの父上の妹の夫の三番目の兄の妾の叔母じゃ。**
- 哦呵呵，怎么打起来了？妾身也要玩。  →  **おほほほ、何やら面白そうね。妾も混ぜてちょうだい。**

### 一人称「我」

- 不愧是我弟，无懈可击的架势……那就出猛招打出破绽来吧！  →  **さすがは我が弟、隙のない構え……ならば猛攻で隙を作り出すまで！**
- 不过掌派人似有负伤，我得过去慰问才行。  →  **ですが掌派人は怪我をされたようですし、お見舞いに行きませんと。**
- 什么……我们掌门败了？这、这……。  →  **何だと……我らの掌門が敗れた？そ、そんな……。**
- 都是我们学艺不精，下回可没那么容易让你们破阵了啊！  →  **我らが未熟でした、次回はそう簡単には陣を破らせませんよ！**
- ……赵兄，请你为我二人见证仲裁。  →  **……趙兄、我ら二人の立会人をお願いする。**

## 語尾・役割語


### 語尾「っす」

- 都说了这么久话，还来训我吗？  →  **散々喋っておいて、まだ僕に説教っすか？**
- 当务之急，是要把小师妹送回山上。  →  **今一番大事なのは、小師妹を山へ送り届けることっす。**
- 多谢惠顾！  →  **毎度ありっす！**
-   →  **{size=24}三つ数えたら、みんなで一斉にかかって、不意を突くっすよ。{/size}**
- 不愧是天底最不应该掌权的那种人。  →  **さすがは天下で最も権力を握らせてはいけない人っす。**

### 語尾「じゃ」

- 从此以后，本门与上官世家，注定势不两立了。  →  **今後、本門と上官世家は、不倶戴天の敵となる運命じゃ。**
- 那也不坏便是。  →  **それも悪くないじゃないか。**
- 不止，你还帮我毁尸灭迹，我们是共犯关系。  →  **それだけじゃない。あんたは死体遺棄を手伝ってくれた。私たちは共犯関係。**
- 那我能跟吗？  →  **じゃあ、ついて行っていいか？**
- 其实合力杀死极乐左使的，不止那五人，还有一个幕后黑手。  →  **実は力を合わせて極楽左使を殺したのは、その五人だけじゃない、もう一人黒幕がいたの。**

### 語尾「ですわ」

- 愚不可及。  →  **愚の骨頂ですわ。**
- 公子所言甚是。  →  **公子のおっしゃる通りですわ。**
- 以彼之道还施彼身罢了，不必客气。  →  **相手のやり方をそのままお返ししただけですわ、ご遠慮なく。**
- 你们夫妻鹣鲽情深，又相敬如宾，令人好生羡慕。  →  **ご夫婦仲睦まじく、互いに敬い合っておられて、本当に羨ましいですわ。**
- 但是爹，这样的下人，杀了也只是脏了您的手，不如……。  →  **でも父上、こんな下人、殺しても手が汚れるだけですわ。それより……。**

### 語尾「だぜ」

- 啊，我问归问，其实你否认也没用，我照样杀你。  →  **あ、聞いてはみたが、否定しても無駄だぜ。どうせ殺すから。**
- 这里是蜀中唐门，可不是你江陵南宫世家。  →  **ここは蜀中唐門だ、あんたの庭の江陵南宮家じゃないんだぜ。**
- 不行！我这刀子出了鞘就得捅人见血，不然收不回去！  →  **駄目だ！俺のこの刀は一度抜いたら血を見るまで収まらないんだぜ！**
- 要不是有外堡可以躲，方才那一阵我们就得全军覆没了。  →  **外堡に隠れられなきゃ、さっきの一戦で全滅してたところだぜ。**
- 我打他不奇怪，你这样美貌的小娘子护着他才奇怪。  →  **俺がこいつを殴るのはおかしくねぇが、あんたみてぇな美人がこいつを庇うほうが奇妙だぜ。**

### 語尾「でござ」

- 对不住，是奴婢说错了，我自行掌嘴。  →  **申し訳ございません。奴婢の言い間違いでございます。自分で頬を打ちますので。**
- 唐门家主信物，除了掌门令牌之外，还有一枚碧血玉，对吗？  →  **唐門当主の証は、掌門の令牌の他に、碧血玉がもう一つ、そうでございますね？**
- 既然如此，我便退下了。  →  **左様でございますか、では私は下がります。**
- 大师，您说是吗？  →  **大師、そうでございましょう？**
- 上官大人，这……此话当真吗？  →  **上官殿、それは……本気でございますか？**

### 語尾「ぜよ」

- 哎，好。今日就教你一招全真派的定阳针吧。  →  **ああ、よかろう。今日は全真派の「定陽針」を伝授して進ぜよう。**

### 語尾「かしら」

- 说起来师弟……啊，该叫你赵、赵少侠？还是说唐少侠？你改宗入室了吗？  →  **そういえば師弟……あ、趙、趙少侠と呼ぶべきかしら？それとも唐少侠？内弟子にはなれたの？**
- 哎耶恶……哥哥你动情的脸真的好可怕，我哥哥知道你会这样吗？  →  **うわキモッ……お兄ちゃんの発情した顔、ほんと怖いんだけど。実の兄上が知ったらどう思うかしら？**
- 会吗？狮子也是为了吃饱活下去啊，先不说这些了。  →  **そうかしら？ 獅子だって満腹になって生きるためじゃない。そんなことより。**
- ……敢问龙姑娘，找我夫君何事？  →  **……お尋ねするけれど龍さん、私の夫に何の用かしら？**
- 好、好主意！我怎么没想到呢？  →  **い、いい考えね！ なんで思いつかなかったのかしら？**

### 語尾「やがる」

- 这可憎的家伙，用心如此歹毒！  →  **あの憎き野郎、どこまでも性根が腐ってやがる！**
- 你这什么屁话！要打也是打你好吧！  →  **なんてふざけたこと言いやがる！殴るならお前を殴るに決まってんだろ！**
- 我什么都没说，你笑个屁。  →  **俺は何も言ってないぞ、何笑ってやがる。**
- 笑死我了，就凭你这三脚猫功夫的货色，也好意思冒充叶云舟？  →  **笑わせやがる、こんな三流以下の腕前で、よくも葉雲舟を騙ったな？**
- 你……你作什么！  →  **お前……何しやがる！**

### 語尾「だわ」

- 哇哈哈，师姐真是一针见血，本梅也觉得自己出了大问题。  →  **ワハハ、師姉の言う通り図星だわ。アタイも自分は相当重症だと思う。**
- ……说得也是，不大方便，可我真的舍不得。好不容易才有的家。  →  **……それもそうね、不便だわ。でも本当に名残惜しい。やっとできた家なのに。**
- 远郎，我气消了，我醒了。  →  **あなた、もう気は済んだわ、目が覚めたの。**
- 哇！你欺负人！我不跟你玩了！  →  **わーん！いじめだわ！もう遊ばない！**
- 那倒是……下回别开这种玩笑，我听了很不愉快。  →  **それもそうね……次はそんな冗談やめて、聞いてて不愉快だわ。**

### 語尾「ですの」

- 既然如此，青城的事再另觅人选吧。  →  **そういうわけですので、青城の件はまた別の人選を考えましょう。**
- 叔公，请您暂时回避，这位赵少侠，想必有话要对我说。  →  **叔公、暫し席を外していただけますか。こちらの趙少俠は、私に話があるようですので。**
- 我们来送奖金，唐门就是这样欢迎的吗？  →  **賞金をお持ちしましたわ。唐門の歓迎とはこういうものですの？**
- 我们来送奖金，唐门就是这样欢迎的吗？  →  **賞金をお持ちしましたわ。唐門の歓迎とはこういうものですの？**
- 是，是，兹事体大，还请容我再考虑考虑，告辞。  →  **は、はい、重大なことですので、もう少し考えさせてください。失礼します。**
