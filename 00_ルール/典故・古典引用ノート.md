# 典故・古典引用ノート

Wandering Sword の台詞は**儒・道・侠**を絡めて武侠の大義を論じる構成が多い。
古典の引用に出くわしたら、**ゼロから訳し直さず、定番の日本語(読み下し・定訳)を当てる**。
散文化・現代語化で潰さない。引用と気づくことが第一歩。

## 扱い方(一般原則 ― これが本体。下の表は代表例にすぎない)

下の表は**ある参考訳に出た分の代表例**であって、本編の引用はこれに限らない。だから手順はこう:

1. **引用を見抜く**: 文言調・対句・四字句・詩のリズム・「子曰く」調・故事めいた比喩が出たら、**古典の引用**を疑う。
2. **出典を同定する**: 下記「定番カノン」のどれかを、**自分の知識で**特定する。
3. **定訳を当てる**: その句の**確立した日本語(読み下し文・有名訳)**を知識から想起して当てる。
   有名な経書・唐詩・成語の読み下しは標準形がある。創作的な散文に言い換えない。
4. **同定できなければ潰さない**: 出典不明なら、漢語の形と調子を残したまま訳す(`fixes`に入れず現状維持でも可)。
   (sandboxのネットが使えるなら語の確認に web 検索してもよいが、基本は知識で足りる。)

### 定番カノン(この時代の武侠が引く出典群)
- **儒(経書)**: 四書(大学・中庸・論語・孟子)、五経(易・書・詩・礼記・春秋)。
- **道・法・兵(諸子)**: 老子・荘子(道家)、韓非子・商君書(法家)、孫子・呉子・三十六計(兵法)。
- **史書の成語**: 史記・漢書・戦国策・資治通鑑(例「鶏口牛後」「四面楚歌」「臥薪嘗胆」等)。
- **詩詞**: 唐詩(李白・杜甫・王維・白居易・李商隠…)、宋詞(蘇軾・辛棄疾・李清照…)、于武陵ら。
- **仏・禅**: 般若心経・金剛経、禅語(武侠の僧・道人の台詞)。
- **民間**: 諺・歇後語(後半を言わせる言い回し)。

> 要するに「特定作家の語録」ではなく、**中華古典の素養そのもの**を当てにする。
> 下表は出発点。出会った引用は、このカノンから同定して定訳を当てていく。

## 字形の原則(読み下しは日本語標準字形で)
- 読み下し・定訳に当てる際、**漢字は日本語の標準字形へ**(中国語の異体字を残さない)。
  例: 醉翁の意は酒に在らず → **酔翁**の意は酒に在らず(醉→酔)。后→後、観→観 等も同様。
- 有名な故事成語は**定着した日本語の言い回し**を優先(例「酔翁の意は酒に在らず」「螳螂蝉を窺う」)。

## 扱いの原則
- 引用は**資産**。MT臭ではない。平準化(現代散文化)は誤訳と同じ。
- 有名な句は上記の定訳・読み下しを優先。無い句は漢語の形と調子を残す。
- 出典が曖昧な引用は、無理に直さず現状維持でよい。
- 儒(秩序・大義)・道(自然・超然)・侠(信義・反骨)の三つの色を、語彙で塗り分ける意識を持つ。

## 傾向(2026-06-20 一斉処理で判明)

実際に本編から拾った引用の出方・見つけ方・落とし穴。

### どこに出るか
- **CG表/Npc の独白・回想・戦闘前の名乗り**に集中。話者は高人(武当=道家、少林=仏、天剣宗、各派長老)＋衒学キャラ(謝学士)。
- 儒(論語・易経)、道(楚辞・内丹詩・咒)、仏(唯識・念仏)、詩(詩経・楚辞・唐七言)、武術古典(太極拳論)、賦(鮑照)と**カノン全域**から引く。

### 見つけ方(機械シグナル)
- **仮名ゼロ**の対話本文＋次のいずれか: 古典助詞 `兮哉乎矣焉耳`、漢文前置詞 `于於`、漢文否定 `不X`、対句・四字句のリズム。
- ツール: `_tools/scan_untrans_rank.py`(中国語信号でランク)。`于/於`は別途要チェック(助詞セットに入れ忘れやすい。龍戦于野を取りこぼした実例)。

### 落とし穴(重要)
1. **技/招式の名前は、易経等の古典由来でも固有名詞＝読み下し禁止。** メニュー表示の技名と一致させること。例: `龍戦于野`『潜龍勿用』(易経乾坤由来だが Skills技能表 の招式名)。キャラが戦闘で叫ぶのは「技名コール」であって朗唱ではない(「四象無極功！喝！」と同型)。Skills技能表に同名があれば原語維持。
2. **念仏はそのまま。** `南無阿弥陀仏`等は読み下し化しない([[南無阿弥陀仏 inconsistency]]も参照、別ファイル)。
3. **人名のzh一致は誤検出。** 「生印令君・段履霜」等は引用でなく固有名詞。
4. **保留キャラ(宇文逸)でも典故は訳す。** 典故はペルソナ非依存だから。止まるのは声・呼称のみ([[保留キャラと非依存修正]])。

### モデル依存(なぜOPUS直轄か)
出典同定と定訳/読み下しの想起は、**モデルの内部知識＋推論性能に強く依存する**。怪しい断片を「有名詩のもじり」と見抜いて当てる/逆に「技名だから触らない」と判断するのは、知識と文脈推理の合わせ技。下位モデルは**「引用らしい」と気づいて旗を立てるまで**に留め、同定・読み下し・触る/触らないの最終判断はOPUSに回すのが安全。誤同定・誤読み下しは典故を潰す(=平準化と同じ害)。
