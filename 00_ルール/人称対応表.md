# 人称対応表(原文の自称・呼称 → 日本語)

中国語の一人称はほぼ「我」一択で、直訳しても個性が出ない。
代わりに**原文の"自称語"と"二人称・敬語の格"**を手がかりに、日本語の人称を訳し分ける。
画一的な「私」を避け、キャラの身分・性別・年齢・性格に合わせること。

## 自称語 → 日本語一人称(目安)

| 原文の自称 | 含意 | 日本語一人称(例) |
|---|---|---|
| 老夫 | 年配の男の自称 | わし／老いぼれ |
| 老身 | 年配の女の自称 | わたし(老女)／この年寄り |

| 贫僧／老衲／小僧 | 僧 | 拙僧／それがし／(老)わし |

| 某／〇某(燕某) | 武人のそっけない自称 | それがし／〜某(燕某のまま可) |

## 二人称・敬語の格 → 口調の硬さ

| 原文 | 含意 | 反映 |
|---|---|---|
| 您／阁下／足下／尊驾 | 丁寧・敬う | 敬体、二人称「あなた/貴殿」 |
| 你 | 普通 | 常体可、二人称「君/お前(関係次第)」 |
| 汝／尔 | 古風・見下し・親密 | 古語調 or ぞんざい。「汝/お前」 |

## 使い方
1. 校正でその話者の**原文**を見て、自称語・二人称を拾う。
2. 上表で日本語人称の候補を選び、`10_人物/<話者>.md` の「原文の自称(根拠)」と「口調・癖」に従う。
3. **一人称は相手・場面で訳し分けてよい(register変化)**。原文の自称が変われば訳も変える
   (例: 老師が 弟子へ=わし、道門で=貧道、対外で=この老いぼれ)。これは表記ゆれではなく**個性**。
   ただし**同じ相手・同じ場面では揺らさない**。正すのは**根拠のないランダムな揺れ(MTノイズ)だけ**。
   揺れには「原文の自称の違い」か「相手との関係」の根拠が要る。根拠を示せない揺れは統一する。
4. 端役で手がかりが無ければ無理に凝らず、身分相応の自然な人称でよい(過剰な飾りも禁物)。
