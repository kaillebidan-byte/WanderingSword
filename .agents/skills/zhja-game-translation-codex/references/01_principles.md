# 01 翻訳憲法 ── 判断の原則

全フェーズ・全モデル共通の前提。迷ったらここに戻る。

## 1. レジスター一致が最上位原則

「原文が荘重なら訳も荘重に、下世話なら下世話に」。直訳/意訳の選択はこの原則の従属変数にすぎない。
高評価訳(活侠伝JP-MOD)の分析で確認された非対称性:

- **格式の高いもの**(詩・格言・書簡・専門語)ほど直訳・訓読へ寄せる。
- **格式の低いもの**(悪態・掛け声・軽口)ほど翻案へ振り切る。

## 2. 直訳と翻案の境界線 ──「字面が通るか」

場当たりで決めない。判断軸は「漢字をそのまま移して日本語話者に意味と語感が通るか」。

- **通る → 漢字温存(直訳寄り)**: 武侠の基幹語彙(内力・軽功・境界)、日中共有の四字熟語(四面楚歌・臥薪嘗胆)、固有武功名・人名・道号。字面が専門用語として機能するものは訳さない。
- **通らない → 意訳・翻案**: 口語俗語・罵倒(媽的・王八蛋)、視認性優先のUIコマンド(捅人→攻撃)、ギャグの構造(很是用力踢→つよつよ蹴り)。字面を捨て、原文が生んでいた効果(悪態の強度・操作の分かりやすさ・笑い)を日本語で作り直す。
- **中間帯 → 意味を残す軽い意訳**: 字数調整・明確化のための言い換え(粹毒→毒精製、槍棍→長物)。

## 3. 守る硬い線は2本だけ

1. **意味・事実・語気の方向を反転させない**。疑問/勧誘/推量/詠嘆/肯定否定の別を保つ。例:「口福了！(=ご馳走にありつける)」を「打つな！(禁止)」にするのは意訳ではなく意味反転の誤訳。
2. **脚色禁止**。原文に無い心情・事実を足さない。崩してよいのは表現であって内容ではない。

この2本の内側では、語順を組み替え、冗長な連体修飾を削り、こなれた日本語に大胆に差し替えてよい。**中日の逐語訳は必ず固く冗長になる**。「意味は通るが日本語として硬い・くどい・翻訳調」は、それ自体が欠陥である。

## 4. カノン資料も検証対象

設定正本、人物資料、用語集、関係性マップ、完成例は、原文を読むための補助資料であって、原文を上書きする答えではない。

- 資料の断定が、原文では人物の誤認、伝聞、嘘、演技、推測、言いさしになっていないか確認する。
- 死亡、血縁、正体、動機、所属、裏切り、時系列は、客観事実と人物の認識を分離する。
- 一つの規則が全時系列・全相手・全分岐を説明している場合、整合性ではなく過剰一般化を疑う。
- 根拠が既訳、完成例、過去ログだけなら、カノンとして採用しない。
- 原文と資料が衝突したら、訳文を資料へ合わせず、`CANON_DOUBT / source-doc-fix / unresolved` として資料側を検証する。

疑義をもっともらしい説明で埋めない。作品がまだ明かしていないことは、訳文でも明かさない。

## 5. 声の非平坦化 ── この仕事の目的

一人称修正・用語統一・誤訳ゼロは**前提であって目的ではない**。目的は「このキャラが、この場面で、この相手にどう喋るか」の再現。

- 原文の一人称はほぼ「我」一択。話者情報は日本語の役割語(一人称・語尾・敬語)という別チャンネルに載せ替える。**訳文だけで話者が分かる**のが到達水準。
- 多モードキャラ(丁重↔はしゃぎ、風雅↔殺意)の**モード落差・比喩・相槌を平板に均さない**。
- 一律の「です・ます」化は最大の平板化要因。敬体/常体は話者の身分・関係・場面で選ぶ。

## 6. 情報を削らない

長大な文でも、原文の反復・対句・比喩を省略せずに移植する。冗長性の除去より情報量の保持を優先する(高評価訳の一貫した姿勢)。削ってよいのは日本語で文脈から自明になる主語・代名詞だけ(→03の直訳臭の節)。

## 7. 強度を薄めない

武侠は生死の世界。「殺す」「斬る」「血」「滅ぼす」等の直接表現を婉曲にしない。怒り・憎しみ・殺気・嘆きを所作や余韻に逃がして薄めない。**婉曲・上品化・マイルド化は誤訳と同じ**。固有名詞・技名に含まれる「殺」「魔」「血」「毒」もそのまま残す。

## 8. 古典引用は資産

漢詩・成語・故事・経書の引用は世界観の核。平易な現代語への言い換え(散文化)は平坦化と同罪。カノン同定→定訳・読み下しの手順は 05_terminology の典故節が正本。

## 9. 迷ったときの最終基準

「この人物が、この場面で、日本語話者だったらどう言うか」。
雅味は語彙と所作で添える。迫力・残酷さ・感情の強度は原文どおり保つ。
判断できないものは捏造せず、旗(conf:low / # REVIEW / CANON_DOUBT)を立てて上位判断へ回す。
