# 10 呼称・敬称・敬体・上下関係を分離する

中国語ゲーム翻訳では、関係語や敬称がある行を日本語の敬体へ自動変換しやすい。しかし、次の要素は別軸であり、個別に判定する。

1. **関係呼称**: 師兄、師弟、師父、叔父、兄上、少侠など
2. **名指し・敬称**: 姓名、役職、殿、様、先生など
3. **文末の敬体**: です・ます・ございます
4. **行為の敬語**: 申す、伺う、くださる、おられる
5. **役割上の上下**: 師から弟子、兄から弟、主君から臣下など
6. **場面上の距離**: 公的、私的、儀礼、叱責、慰め、敵対

## 1. 関係呼称は文末敬体を要求しない

`師弟` や `弟子` のような語は、人物関係と役割を示す。呼びかけ自体に敬意や親しさがあっても、話者が上位・年長・指導役なら、自然な日本語は常体になることが多い。

例:

- 不自然: 「宇文師弟、今日は早く休んでください」
- 自然: 「宇文師弟、今日は早めに休め」
- 柔らかくする場合: 「宇文師弟、今日は早めに休むといい」

`宇文師弟` を残すかどうかと、`ください` を使うかどうかは別に判定する。

## 2. 上位者への敬称と、下位者への語尾を混ぜない

一つの文で、話者が目上を敬いながら、目下へ常体で説明することがある。

- 「師父は普段ここで門務を執られる。重大な事があれば、師伯や師叔も集まる」

この場合、`執られる` は師父への敬意であり、聞き手への敬体ではない。全文を `〜されます／〜集まります` にする必要はない。

## 3. 丁寧さを一つのスイッチにしない

同じ人物でも、次を独立して選ぶ。

- 呼称は敬意あり、語尾は常体
- 呼称は名指し、語尾は丁寧体
- 呼称を省略し、行為敬語だけを使う
- 公的場面では重い常体、私的場面では柔らかな常体
- 敵対場面では役職名を残しつつ、反語・断定を強める

## 4. 監査手順

各発話で次を順番に決める。

1. 誰が誰へ話しているか。
2. 関係は成立前か後か。離反・和解・正体判明の前後か。
3. 呼称が担うものは敬意、親しさ、役割、儀礼のどれか。
4. 話者は聞き手より上位・同格・下位のどこか。
5. 場面は案内、命令、慰め、謝罪、儀礼、敵対のどれか。
6. 呼称、文末、行為敬語を別々に選ぶ。
7. 前後行とつないで、同じ軸が不自然に揺れていないか確認する。

## 5. 典型的な誤り

- `师弟` を見て、兄弟子から弟弟子への全文を敬体にする。
- `您` をすべて「あなた様」にする。
- 師父への尊敬語を、聞き手への丁寧語と混同する。
- 呼称に敬意があるため、命令や叱責まで和らげる。
- 親しい相手なので、儀礼上必要な役職呼称まで消す。
- `お前／そなた／あなた` の一語だけで人物差を作る。

## 6. 修正束の作り方

呼称だけを一括置換しない。次のように同じ崩れ方と場面で束ねる。

- 入門直後の案内・教導で、関係呼称は正しいが語尾だけが過剰敬体
- 公的号令で、役職名は正しいがサービス敬語へ平坦化
- 病床で、敬称は正しいが文が長く整いすぎている
- 敵対場面で、役職呼称を理由に語気が弱められている

修正後も、関係呼称、敬称、文末、行為敬語の四層を個別に再検査する。
