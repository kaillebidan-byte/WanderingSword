# 03 スタイルガイド ── 文体・定訳・直訳臭

翻訳作業の毎バッチで参照する実務基準。例はすべて実在の高評価訳・実運用プロジェクトから。

## 1. 文体アーキテクチャ(4層)

| 層 | 基本文体 | 要点 |
|---|---|---|
| 地の文 | 常体(だ・である)。です・ます不使用 | 二人称は場面の温度で「あなた/お前/君/主語省略」を訳し分け。長文は句点で分割・再構成 |
| 会話 | 話者ごとに役割語を設計 | 一人称・語尾・敬語で話者識別(→04)。罵倒はローカライズ、皮肉は強度保持 |
| 戦闘・内心 | 短文・体言止め・破調 | 掛け声は擬声語音写。心内語は()で明示し**常体**(ですます禁止)。自嘲は詠嘆で |
| UI・システム | 体言止め・単語止め・字数厳守 | 表示欄は漢字1字流用(儲→保)、説明文は読みやすく開く |

**地の文の内部にも二層構造**: 現代語の常体で全体を進め、詩句・格言・書簡・碑文・技の名乗りだけ訓読調・候文へレジスターを上げる。文体の変化だけで「作中作を読んでいる」と体感させる。
例: 書簡「葉氏の節は泉壌に告ぐべく…岳珂謹啓」(候文)、技の名乗り「煙波の老釣叟。酔うもまた求め難し」(訓読)。

## 2. 直訳臭(MT臭)の三大要因と対処

ゼロ翻訳でも逐語で起こすと同じ症状が出る。**最初から出さない**。

1. **明示代名詞の冗長反復**: 中国語は主語・二人称を毎回出すが、日本語は文脈で落とす。同一発話内で明示の一人称・二人称を2回以上出さない(強調が要る1回に絞る)。
   例: ×「私は決めた。たとえ何があっても私が止める」→ ○「決めた。たとえ何があっても、私が止める」。
   温存してよい反復: 感情の絶句(「あなたは……あなたは……」)、対句(「私は陰、あなたは陽」)、三連レトリック、別人への呼称。
2. **直訳調の語順・冗長表現**: 中国語の構文をそのまま並べない。「〜することができる」→「〜できる」。連体修飾の多重連結は分割。
   例: 「名剣山荘の者たちも攻撃を受けているかもしれませんが、配下には腕利きの者が多く、たとえ攻撃を受けても一時的には無事でしょう」→「名剣山荘も襲われているやも。だが配下は腕利き揃い、しばらくは持ちこたえるはずだ」。
3. **一律の敬体化・声の平坦化**: 全員が無難な「です・ます」で喋る訳は死んだ訳。敬体/常体は関係とモードで決める(→04)。

## 3. 字形の原則

- 訳文の漢字は**日本語標準字形**へ。簡体字・中国語異体字を残さない(们/这/个、丐帮→丐幇、真气→真気、达摩→達磨)。
- 人名は新字体化(鐵冠道人→鉄冠道人)。地名・宗派の固有名詞は原字保持を基本とする(崆峒・峨嵋)。
- 読み下しも日本語字形(醉翁→酔翁)。

## 4. 定訳表(繰り返し出る要素)

### 笑い(平仮名を原則とし、意図的な破調だけ例外)
| 原文 | 訳 | 含意 |
|---|---|---|
| 呵呵 | ふふ | 含み笑い・慎重 ※男性快活キャラには「はは」基調に調整可(ペルソナ優先) |
| 哈哈 | はは | 快活 |
| 嘿嘿 | にやり/くっく | 悪戯・含み |
| 冷笑 | 冷ややかに笑う/鼻で笑う | — |
| 哼 | ふん | 不満の鼻。文脈で嘲笑にも |

- 通常の笑いは平仮名を原則とする。悪役・怪人の異様さ、濁り、伸びを意図的に演出する場合は、人物別の根拠を記録したうえで `ケヒヒィ` のようなカタカナ破調を許容する。

### 悪役・怪人・雑兵・端役の演出強度

- この規則の対象は、悪役・敵役・怪人・雑兵・癖の強い端役の**人物声**である。善玉の忠誠表現、一般の比喩、成語の強調などへ横展開しない。
- 悪役・端役を主要人物と同じ無難な自然会話へ均さない。短い登場時間でも、悪意、異様さ、卑俗さ、役割差が識別できることを優先する。
- 実地例では、白無常の `小僧ォ、今のお前の相手は――この白と黒だよ` と、黒無常の `ケヒヒィ……油断すりゃ、命を落とすぞォ` まで演出を強めた。これは「悪役・怪人なら、この程度の強度まで攻めてよい」という許容例である。
- 黒無常・白無常は端役一般の代表口調・標準人格ではない。`そうなのかァ / ヒヒヒィ / 黒爺 / この黒` を含む具体的な語尾、自称、笑い方、性格は別人物へ流用しない。
- 原文の笑い、引き伸ばし、反復、尊大さ、卑俗さ、奇矯な自称、脅し、場面上の役割に根拠がある場合は、同程度の破調や誇張を人物ごとに新しく設計してよい。
- 現実的な自然さより、登場時の印象、敵種別、戦闘前後の温度を優先してよい。ただし原文にない性格・情報・残虐性は追加しない。
- 名もない山賊も全員を同じ没個性な口調へしない。頭目、参謀、臆病者、粗暴な手下など場面上の役割が読める場合は、語彙とリズムを誇張して差をつける。

### 咳(機能で分ける——MTはここを必ず壊す)
- 本物の咳(病人・むせ): 咳咳→「ゴホ、ゴホ」。
- 取り繕い・照れ隠し・話題転換の咳払い: 文頭の咳咳→「コホン」「オホン」。健常者の文頭咳咳を「げほげほ」にすると病人化する。
- 喀血(咳血/咯血): 血の描写を明示(「ゴホッと血を吐く」)。
- 呻き(哼/呻吟): 咳ではない→「うう」「ぐっ」。

### 罵倒・俗語(直訳せずローカライズ。強度は保つ)
| 原文 | 訳 |
|---|---|
| 媽的 | くそ |
| 去你媽的 | くたばれ |
| 王八蛋 | ろくでなし |
| 臭+人(臭和尚/臭小子) | 生臭坊主/くそ道士/小僧・青二才 ※字義の「臭い」にしない。ただし乳臭い=青二才、臭い飯=実臭は正 |
| 戰你娘親 | ぶちのめしてやる/(演出タグ付きなら)喧嘩上等だ |

### 誤訳しやすい語(実プロジェクトの発見ベース)
- 区区: へりくだり。「私/ささやかながら」。「あなたごとき」と侮蔑誤訳しない。
- 小友: 年長者の親愛呼称。「小友」のまま/「若いの」。見下しに潰さない。
- 师弟/师兄: 兄弟弟子。「弟子」「実弟」と取り違えない。向きを必ず確認。
- 她老人家: 敬称。「お年寄り」ではない。
- 公門: 役人/官憲/捕快。「公務員」等の現代職名にしない。
- 催谷(内力): 無理に振り絞る/激発させる。「催促」ではない。
- 一盞茶: 直訳「茶一杯の間」よりも「ほんのひととき」等、文脈の自然さ優先(ただし世界観の時間単位として活きる場面は残してよい)。

## 5. 口語のテンポ

- 擬声語は**反復回数まで一致**させて音写: 汪汪汪汪汪！→ワンワンワンワンワン！
- どもり・言い淀みは読点区切りで音レベル再現: 告告告辭→「い、い、い、暇乞い」/ 突、突然→「き、急に」。
- ダッシュ(──)による中断・絶句は踏襲する。
- 全角スペースで息継ぎ・間を作ってよい(タグ内の長台詞等)。

## 6. タグ・改行の保全(鉄則)

- 制御タグ(`{size=}` `{punch=}` `<Y>…</>` `{0}` 等)は**位置・入れ子を原文と完全一致**させ、中身だけ訳す。
- UEリッチテキストの閉じタグは常に `</>`(`</Y>` 等の名前付き閉じは破損)。
- 改行(`\n` `#nl` `\r\n`)は原則、原文の文単位と1対1対応。
- 話者区切り(`$@$` 等)より前(ID・話者名)は不変。本文だけを訳す。
- 空文字列エントリは空のまま。`不翻译/不翻譯` を含む内部データは訳さない。

## 7. UIの二本立て

同じ語でも、**省スペースの表示欄では漢語1字を流用し、説明文では読みやすい訳語に開く**。
例: 戦闘表示 `氣{0}` は「氣」のまま、解説文中は「気力」。1字タブ(煉/發/儲)は必ず1字の日本語漢字(錬/発/保)に。

## 8. 用語の型(命名の参考)

- UIコマンドは機能名に意訳: 捅人→攻撃、備揍→防御、絕招→必殺。
- 状態異常「名」は1語に固定して全出現統一(例: 失衡→蹌踉)。同じ字が一般動詞で出たら文脈訳(「体勢を崩す」)——名と動詞を区別する。
- 二つ名・称号は漢字圧縮の妙で: 千面人魔/前武林盟主/上官家令嬢。世家は「家」を補う(南宮婦人→南宮家婦人)。
- 門派+弟子は「派」の有無で補完判断: 嵩山弟子→嵩山派弟子(「山」だけでは流派とわからない)/唐門弟子→そのまま(「門」を含む)。
