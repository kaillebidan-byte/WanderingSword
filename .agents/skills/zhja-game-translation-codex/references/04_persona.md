# 04 ペルソナ設計システム ── 声の作り方と守り方

キャラクター翻訳の品質はペルソナ文書の質で決まる。ここが最も繊細なA級判断であり、**作成・拡張は監督直轄**。ワーカーはペルソナを読んで従うだけで、拡張しない。

## 1. 確定関門(役割分担の要)

各キャラのペルソナ文書に `status:` を持たせ、着手可否を**statusで機械的に判定**する:

- `status: 確定` → 翻訳ワーカーが本文翻訳に着手してよい。
- `status: 仮訳` または文書なし → **着手せず停止して報告**。「<キャラ>はペルソナ未確定。監督での確定が必要」。
- `status: 保留` → 方針相談中。触らない。

理由: ペルソナ確定は「原文から声を起こす」最も繊細な判断で、失敗すると数百〜数万行が均質に汚染される。確定済みペルソナへの追従は足場が効くためワーカーで安全(実運用で実証済み)。

## 2. ペルソナの作り方(監督手順)

素材は**原文(zh)**。訳文や機械訳から起こさない(品質の循環参照を避ける)。

1. **統計を取る**: そのキャラの全原文行から自称語(我/在下/老夫/本座/贫道/弟子…)・二人称(你/您/汝)・呼称マーカー(○○师兄/师父/姑娘/大哥…)の出現数を集計する。
2. **声の核を1段落で書く**: 身分・年齢・性格・話し方の芯。「折り目正しく素直、探究心が強く問いかけが多い」のように、翻訳判断に直結する形で。
3. **一人称を確定する**: 下の人称対応表と語調型録から選ぶ。
   - 大物キャラは**一人称を1つに固定し、register差は敬度・語尾・呼称で出す**のが安全(ワーカーが揺らさない)。
   - 原文の自称語が変わる場面(在下/弟子/為兄)は「人称交替」ではなく「名乗り・謙譲の定型」として例外規定に書く。
4. **モード表を作る**: 相手カテゴリ×敬度のマトリクス(下の様式)。バッチ分割の単位にもなる。
5. **完成例を書く**: モード別に最低3例、**原文から自分で訳した手本**を対訳で載せる。これが声の正本。機械訳・仮訳を手本にしない。
6. `status: 確定` に上げ、根拠(zh統計)を残す。

## 3. モード表の様式(実例: 武当育ちの主人公)

| | モード | 主な相手 | 敬度・語尾 | 一人称/名乗り |
|---|---|---|---|---|
| M1 | 師門・弟子 | 師父・師伯・師叔・師兄 | 丁重(です/ます)。師父にははしゃぎ可 | 私/定型は自称「弟子」 |
| M2 | 義兄弟・仲間 | 盟友たち | 常体・打ち解け(〜だろう/〜しよう) | 私 |
| M3 | 後輩・弟分 | 妹分・師弟 | 温かく諭す常体 | 私 |
| M4 | 江湖・対外 | 他派の長・初対面 | 折り目正しい敬体。高僧へは敬虔 | 私/硬い名乗りはフルネーム |
| M5 | 親密・恋情 | 想い人 | 柔らかい常体・愛称 | 私 |
| M6 | 戦闘・断罪 | 敵 | 短い断定・体言止め・気迫 | 私/名乗りはフルネーム |
| M7 | 心内語(全文括弧) | — | 地の常体。ですます禁止 | 私(多くは自称なし) |

運用上の落とし穴(実運用で確定したもの):
- **心内語の判定は「本文全体が括弧」のみ**。(小声で)(苦笑)等のト書き接頭辞+発話は心内語ではなく発話——registerは相手依存。
- **直前話者≠話しかけ相手**。傍白・第三者への悪態が混じる。宛先は本文内容と原文で判断してから敬度を当てる。
- **呼称は関係の時系列で変わる**(弟子入り前は「道長」「大哥」、入門後は「師父」「師兄」)。原文の呼称語(道长/师父)で判定し、一律適用しない。
- 敵対関係では相手が目上でも敬語を使わない(貴様・お前)。これは高評価訳で一貫していた原則。

## 4. 人称対応表(原文の自称語 → 日本語一人称の目安)

| 原文の自称 | 含意 | 日本語一人称(例) |
|---|---|---|
| 老夫 | 年配男 | わし/老いぼれ |
| 老身 | 年配女 | わたし(老女)/この年寄り |
| 贫道/道号 | 道士 | 貧道/拙道/わし |
| 贫僧/老衲 | 僧 | 拙僧/(老)わし |
| 在下/鄙人 | へりくだり | 私/手前/小生 |
| 晚辈 | 目上への若輩 | 私(謙) |
| 某/○某 | 武人のそっけなさ | それがし/○某のまま可 |
| 末将/卑职/微臣 | 武官・臣下 | 拙者/それがし/私め |
| 妾身/奴家 | 女性の古風な謙称 | わらわ/わたくし/妾 |
| 本座/本教主/本宫 | 高位の尊大 | この私/我(われ)/わらわ(女) |
| 朕/孤/寡人 | 帝王 | 朕/予 |
| 为师/为父/为兄 | 目下への自称 | わし(師)/俺(兄貴分) |
| 洒家 | 粗野な男 | 俺/俺様 |
| 名前で自称 | 幼さ・親しみ | 名前のまま(「鈴はね…」) |

二人称の格: 您/阁下/足下→敬体+「あなた/貴殿」、你→常体可+「君/お前」、汝/尔→古語調かぞんざい。

## 5. 語調型録(型の引き出し——高評価訳から抽出)

キャラの個性に合う「一人称+語尾」の型を選ぶための実例。**特定キャラの模倣ではなく技法だけ借りる**。

一人称の効果(実例の要約):
- 俺=率直・武骨 / 私=端正・理知(男女とも) / 僕=線の細い若者(「っす」と併用で下っ端感) / あたし=蓮っ葉・姉御 / わし=老人・重鎮 / 拙者=堅物の武人 / わらわ・妾=高貴な女 / わっち=花街 / 俺様=尊大 / 本+名(本梅)=三人称的自称の尊大さを一人称化 / 手前=卑屈な小物。

語尾の効果:
- っす=体育会系の下っ端 / じゃ・のう=老人・仙人 / ですわ・ですの=令嬢 / だぜ・だろ=快活な兄貴分 / でございます=従者・商人 / かしら・だわ=気位の高い女 / やがる=荒くれ / ぜよ=豪快な年長者。

三人称的自称の変換技法: 「本娘子這回就不跟你計較了」→「今回は見逃してあげるわ」——自称詞は消えても、押しつけがましさを「あげる」+「わ」に移し替えて保存する。

## 6. モード切替型ペルソナの設計(実運用で確立した型)

落差のあるキャラでは、**固定すべきは語尾ではなく切替条件**。語尾を1つに決めようとすると必ず平坦化する。実例の型:

- **二段落差型**(風雅↔殺意): 既定は雅語の悠然(自称「余」)、スイッチが入ると温度を消した冷たい断定(「あの老僧なら……余が、もう斬った」)。**どちらも薄めない**。殺意を激情として叫ばせない(冷たく断つ)のが落差の作り方。
- **三段切替型**(献身・柔/謙譲/聡明): 恋慕の相手には愛称自称+柔らかい「わたし」、目上には「わたくし」(晚辈の含み)、状況報告では簡潔な分析口調。切替条件=相手と場面。

設計時はモード表に加えて次の3節を書くと声がぶれない(templates/persona_template.md に対応節あり):
1. **発話優先順位**: このキャラが口を開く前に何を優先するか(例: まず相手の身を案じる→自分より相手を守る→的確に補佐する)。
2. **感情表出**: 感情ごとの出し方(例: 恋慕は言葉にせず案じる行動でにじむ/殺意は温度を消した断定)。
3. **言わないこと(思考禁止)**: 声の輪郭は負の制約で決まる(例: 感情を名前で説明しない/落差を均さない/核自称を「私」に潰さない)。

## 7. 端役の扱い

行数の少ない端役(<100行)は凝らない。身分相応の自然な人称・口調でよい(過剰な飾りは逆効果)。呼称はほぼ汎用(少侠・お客人)。ただし世界観口調指針(03)には従う。
