# 07 語調型録 ── 役割語の実例集(高評価訳より)

ペルソナ設計時の「この性格にはこの型」の即引き用。各例は原文→訳の対で、**原文がどう個性づけされたか**を見る。特定キャラの模倣ではなく技法だけ借りる。出典: 活侠伝JP-MOD(検証済みコーパス)。

## 一人称の型

**俺**(率直・武骨・アウトロー)
- 我错了！我错了还不行吗？ → 俺が悪かった！ 悪かったってば！
- 我？我这样的无名小卒，几时劳她费心了。 → 俺？ 俺のような名もなき下っ端に、いつからそんな気遣いを？

**私**(端正・理知。男女とも使える基準線)
- 且慢，我去吧。 → 待て、私が行こう。
- 你们便是二人合力与我相斗，我又何惧之有！ → 君たち二人が力を合わせて私と戦おうとも、何を恐れることがあろう！

**僕**(線の細い若者。「っす」と併用で下っ端感)
- 我哪知道你？ → 僕が君のことなんて知るわけないだろう？
- 赎回外堡好啊，不然我都没位子睡。 → 外堡の買い戻し、賛成っす。じゃないと僕の寝る場所がない。

**あたし**(蓮っ葉・姉御)
- 我怎么知道呢？ → あたしが知るわけないだろ？
- 你可别太得意哦，下回再切磋，就是我向你讨教了。 → 調子に乗るんじゃないよ。次に手合わせする時は、あたしが教えを請う番だからね。

**わし**(老人・重鎮)
- ……老朽想不通。 → ……わしにはわからん。
- 是老夫杞人忧天了。 → わしの杞憂であったか。

**拙者**(堅物の武人・へりくだりの格式)
- 在下唐门赵活。 → 拙者は唐門の趙活。
- 在下山野粗人，说话不得体，也是有的。 → 拙者は山育ちの粗忽者ゆえ、言葉が過ぎることもありましょう。

**わらわ・妾**(高貴・古風な女)
- 哦呵呵，怎么打起来了？妾身也要玩。 → おほほほ、何やら面白そうね。妾も混ぜてちょうだい。

**わっち**(花街・伝法)
- 我就是你爹的妹妹的丈夫的第三个兄长的小妾的姑姑。 → わっちはそなたの父上の妹の夫の三番目の兄の妾の叔母じゃ。

**我(われ)**(格式・所属の誇り)
- 什么……我们掌门败了？ → 何だと……我らの掌門が敗れた？
- 不愧是我弟，无懈可击的架势…… → さすがは我が弟、隙のない構え……

## 語尾の型

**っす**(体育会系の下っ端): 多谢惠顾！ → 毎度ありっす！ / 还来训我吗？ → まだ僕に説教っすか？
**じゃ・のう**(老人・仙人): 注定势不两立了。 → 不倶戴天の敵となる運命じゃ。
**ですわ・ですの**(令嬢): 愚不可及。 → 愚の骨頂ですわ。 / 唐门就是这样欢迎的吗？ → 唐門の歓迎とはこういうものですの？
**だぜ・だろ**(快活な兄貴分): 否认也没用，我照样杀你。 → 否定しても無駄だぜ。どうせ殺すから。
**でございます**(従者・商人): 是奴婢说错了。 → 奴婢の言い間違いでございます。
**かしら・だわ**(気位の高い女): 我怎么没想到呢？ → なんで思いつかなかったのかしら？
**やがる**(荒くれ): 用心如此歹毒！ → どこまでも性根が腐ってやがる！
**進ぜよう**(豪快な年長者): 今日就教你一招吧。 → 今日は一手伝授して進ぜよう。

## 変換技法(型録の使い方の核)

- **三人称的自称の移し替え**: 「本娘子這回就不跟你計較了」→「今回は見逃してあげるわ」。自称詞は消えても、尊大さを「あげる」+「わ」に移して保存する。自称を残す選択もある(本梅→本梅のまま)——キャラの押しの強さで決める。
- **一人称+語尾の掛け算**で身分×性格を同時に表す(僕×っす=気のいい下っ端、わし×じゃ=好々爺、私×ですわ=令嬢)。
- 二つ名・称号の圧縮命名: 千面人魔/前武林盟主/上官家令嬢/小師妹——漢字の格で人物の格を出す。
