# 05 用語・呼称・典故の運用

## 1. 用語ノートの規律

- 1固有名詞=1ノート(またはtsvの1行)。原語・訳語・よみ・根拠・statusを持つ。
- **status運用**: `確定`(動かさない)/`仮訳`(揺れている。使う時は仮である旨を意識)/`議論中`(出力時要確認)。
- **訳語の優先順位**: 確定訳 > 仮訳 > 新規(新規に訳したら必ずノートを作る)。既訳の固有名詞を勝手に言い換えない。
- 検索性のためタグ・関連リンクを整える(巨大資料を常時読み込まず、必要なノートだけ引く運用)。

## 2. 用語翻訳の型(01の境界線の適用)

- **武侠の基幹語彙は漢字温存+新字体化**: 內力→内力、輕功→軽功、真气→真気。
- **技名・武功名・秘伝書名は原語維持**(新字体化のみ)。読み下し禁止。ゲーム内メニューの技名表示と一致させる。戦闘中の技名叫びは「技名コール」であって朗唱ではない——古典由来の技名(易経の卦辞等)でも訳さない。
- **UIコマンド・状態異常名は機能で意訳し1語固定**(→03§8)。
- **単位・貨幣(里・両・銭)は世界観優先**で温存。必要なら初出で軽い注記。
- **参考TMの使い方**: 他作品の高品質対訳(例: 活侠伝コーパス)は語彙の慣例と言い回しの型だけ借りる。**固有名詞の流用は厳禁**(その世界に存在しない門派名を持ち込む事故が実際に起こる)。

## 3. 関係性・呼称マップ

呼称の間違いは誤訳と同じ扱い。特に**師兄/師弟の向き**はMTも人も間違える最頻出事故。

作り方:
1. 原文から呼称マーカー(○○师兄/师父/大哥/○○姑娘/掌门…)を話者×相手で集計し、**出現数つき**で表にする(数が根拠になる)。
2. A表=各キャラ→主人公 / B表=主人公→相手 / D表=キャラ相互(門派・勢力のクラスタ別)。
3. **向きの相互一致を厳守**: XがYを「師兄」と呼ぶなら、YはXを「師弟」と呼ぶ。全箇所で相互に確認。
4. 門派の輩行(世代)を整理する(掌門>長老>兄弟子>弟弟子)。呼称はこの構造から導出。
5. 不明・食い違い(相手は親称なのに自分は「阁下」等)は「要確認」として残し、本文着手時に原文で確定。

運用:
- 敬称(少侠・公子・前輩・道長・幇主)は文脈に合う日本語へ。むやみに「さん」化しない。
- 称号呼び=敬語、あだ名・蔑称呼び=タメ口、という対応を敬語設計のスイッチに使う。
- 親密呼称(愛称・逸児型)を他人行儀に均さない。想い人の愛称は定訳化(「雪児」)し、汎用「お前/あなた」に痩せさせない。

## 4. 典故・古典引用の手順(監督直轄)

武侠の台詞には経書・漢詩・成語・故事が頻出する。これは世界観の核=資産。**散文化は平坦化と同罪**。

手順:
1. **見抜く**: 仮名にできない文言調・対句・四字句・詩のリズム・「子曰く」調が出たら引用を疑う。機械シグナル=古典助詞(兮哉乎矣焉耳)・漢文前置詞(于/於)・漢文否定(不X)。
2. **同定する**: 定番カノンから出典を特定する——四書五経/老荘・韓非・孫子/史記・漢書の成語/唐詩宋詞/仏典・禅語/諺・歇後語。
3. **定訳を当てる**: 確立した読み下し・有名訳を使う(「寧ろ鶏口と為るとも牛後と為る勿れ」)。日本語に定着した故事成語があればそれを優先(「羮に懲りて膾を吹く」)。読み下しの字形は日本語標準形。難読には ルビ的括弧(「坦蕩蕩(たんとうとう)」)。
4. **同定できなければ潰さない**: 漢語の形と調子を残して訳し、`conf:low` の旗を立てる。創作的な散文に言い換えない。

落とし穴:
- **技名は古典由来でも原語維持**(§2)。引用と技名コールを混同しない。
- **念仏・経文はそのまま**(南無阿弥陀仏を読み下さない)。
- 人名・称号の漢字一致は誤検出(引用ではない)。
- **同定・読み下しはモデルの知識に強く依存する**。ワーカーは「引用らしい」と旗を立てるまでに留め、同定と最終判断は監督へ。誤同定は典故を潰す。

## 5. 儒・道・侠の塗り分け

儒(秩序・大義)・道(自然・超然)・侠(信義・反骨)の三つの色を語彙で塗り分ける意識を持つ。僧は仏語、道士は道家語彙、儒者は経書の引用で喋る——話者の思想背景が語彙選択の根拠になる。
