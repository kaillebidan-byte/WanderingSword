# 関係性・呼称マップ(中大キャラ ≥100行 + 主人公)

呼称整合の地図。**端役(<100行)は対象外**(呼称はほぼ汎用「少侠」等)。
データ根拠 = 原文での呼称マーカー出現数 + 各確定ペルソナの二人称欄。
**最終判断は原文と既訳を正本**とする(この表は地図であって、個別の原文文脈を上書きしない)。

## A. 各キャラ → 主人公 の呼び方(原文の出現数つき・関係カテゴリ別)

### A-1. 親・師の慈愛(愛称・幼名)
- (キャラ): (呼称)×N (関係の注記)

### A-2. 親しい兄貴分・身内の愛称
- (キャラ): (呼称)×N

### A-3. 恋慕・特別な呼称
- (キャラ): (原文呼称)×N → **訳=「(確定訳)」**

### A-4. 弟弟子として「○○師弟」← 相手が兄弟子(主人公は彼らを【師兄】と呼ぶ)
- (キャラ): (呼称)×N

### A-5. 兄弟子として「○○師兄」← 相手が弟弟子(主人公は彼らを【師弟】と呼ぶ)
- (キャラ): (呼称)×N

### A-6. 対等・義兄弟「○○兄/兄弟」
- (キャラ一覧+出現数)

### A-7. 敬称「○○少侠」「○○公子」「○○大侠」(礼儀・距離)
- (キャラ一覧+出現数)

### A-8. 汎用呼称のみ(関係が薄い・役割NPC)
- (一覧)

## B. 主人公 → 相手 の返し(Aから導出。★師兄弟の向きは必ず相互一致)
- → (相手) = 「(呼称)」((A-x参照。関係とモードの注記))
- → (相手) = 「(呼称)」【要原文確認: (迷いの内容)】

## C. 要整合チェック
- [ ] 師兄/師弟の向きが全箇所で相互一致しているか(最頻出誤訳)。
- [ ] 特別な呼称(愛称・恋慕)が相手の確定ペルソナと食い違っていないか。
- [ ] A表の関係カテゴリとB表の返しが整合しているか。
